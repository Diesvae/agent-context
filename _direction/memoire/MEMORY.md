# Memory — accumulated lessons

One fact per file, and this index says **when to open** one, never what it contains. A summary
here would be a second writing of the fiche, refreshed less often and consulted more.

This file is loaded at boot, so it is bounded: keep each line under ~200 characters and put
the detail in the file it points at. R10 holds it under the reading ceiling of the tool that
loads it — a loader that truncates does so from the **end**, where nobody looks.

## Method

- [A green guard may be dead](a-green-guard-may-be-dead.md) — open before trusting a rule you have never seen fail.
- [State and journal separate](state-and-journal-separate.md) — four destinations at triage; the fourth is the one that vanishes.
- [Declared beats derived](declared-beats-derived.md) — open before letting a name stand in for a correspondence.
- [A pipeline status can lie](a-pipeline-status-can-lie.md) — open when a check's result disagrees with what is on disk.
