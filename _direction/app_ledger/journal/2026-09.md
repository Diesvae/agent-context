# Journal — Ledger, 2026-09

## 2026-09-17 — the branch is created empty on purpose

A system demonstrated only on its filled branch proves nothing about how it treats an empty
one. Ledger declares one domain and no code, so two properties become testable rather than
asserted: that a skeleton branch still appears in the open register with an empty list, and
that compiling a context for one app does not drag in the other's subgraph.

The dependency on the Notes account API is recorded in the map **before** any code consumes
it. A consumer that exists only in code is invisible to impact analysis until it breaks.
